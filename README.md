# 苹果 M 系列电脑怎么选指纹浏览器？

在 M1、M2 等 Apple 芯片的 Mac 上选「指纹浏览器」，打开“关于本机”，先看“芯片”一栏。官网 Mac 下载区区分 Apple 芯片与 Intel 芯片，按自己机器显示的信息选对应安装包。
[官方资料](https://zwbrowser.com/download/)

## 安装后先验证什么？

打开客户端，建一套不含客户资料的测试环境，在其中访问常用网页。做一次登录、下载一份示例文件，再正常退出并重启。记下 macOS 版本、芯片和客户端版本，这三个信息能帮助区分机型兼容问题与单一网页问题。

## 遇到系统提示怎么办？

记录提示原文，核对文件来源与官方当前版本。如果是单位统一管理的 Mac，把提示交给管理员核对安装策略。系统已经提供的安全校验应按正式发布方和系统的指引处理。
